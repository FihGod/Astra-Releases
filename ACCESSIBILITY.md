# Accessibility

Astra aims to make its download instructions and support information clear and usable. The public repository uses text links and structured Markdown so essential instructions do not depend on images alone.

The Windows application and Linux dashboard have not been independently certified for accessibility. Screen-reader, keyboard-only, zoom, and contrast support may have limitations; no WCAG conformance claim is made.

Report an accessibility barrier with the public bug report template, or use a private support ticket if it involves account information. Include the application version, operating system, assistive technology or browser, the task you were trying to complete, and the barrier encountered. Please suggest a workaround if you found one.
