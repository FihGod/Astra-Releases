# Contributing to Astra

This is Astra's public downloads and documentation repository. The application source is maintained privately.

## Bugs and suggestions

Use the bug report or feature request template for public, non-sensitive feedback. Include your Astra version, operating system, reproduction steps, and what you expected to happen. Remove account information and secrets from screenshots and logs.

For billing, login, license access, or account-specific help, use Astra's Discord support tickets instead of a public issue. For vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Documentation changes

Small documentation corrections are welcome through pull requests. Explain the change and check links and formatting. Discuss larger changes in an issue first.

Do not submit application binaries, release assets, private application source, signing material, customer data, or generated logs. Only maintainers publish official releases. A documentation contribution does not change the licensing of Astra's application.

Follow the [code of conduct](CODE_OF_CONDUCT.md).
